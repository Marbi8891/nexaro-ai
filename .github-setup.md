# Cómo subir a GitHub

## Paso 1 — Crear repositorio en GitHub

1. Ve a https://github.com/new
2. Nombre: `nexaro-ai`
3. Descripción: `Sistema de captación de leads con IA — NexaroAI Agency`
4. Visibilidad: **Private** (recomendado, contiene tu lógica de negocio)
5. NO marques "Add README" ni nada más
6. Clic en **Create repository**

## Paso 2 — Subir el proyecto desde tu ordenador

Descomprime el ZIP y desde la carpeta `nexaro-ai/`:

```bash
git init
git add .
git commit -m "feat: initial commit — NexaroAI full-stack system"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/nexaro-ai.git
git push -u origin main
```

## Paso 3 — Verificar que .env NO se subió

```bash
git status
# No debe aparecer ningún archivo .env
```

## Paso 4 — Conectar Render al repo

Una vez el repo está en GitHub:
1. Ve a render.com → New Web Service
2. Conecta tu cuenta de GitHub
3. Selecciona el repo `nexaro-ai`
4. Root Directory: `backend`
5. Sigue las instrucciones del README principal

---

> El archivo `.env` está en `.gitignore` — nunca se subirá.
> Usa `.env.example` como referencia para configurar las variables en Render.
